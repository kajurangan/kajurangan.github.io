Case study: BMO Collections Dialer

BMO's collections team calls customers from lists produced by an on-premises dialer. The migration moves that work to Amazon Connect, which means every dialer file has to be picked up, checked, secured, and turned into customer profiles without a person touching it. I built these parts of the pipeline:

  1. Pick up and validate. A Lambda validates inbound CACS dialer files, splits them by record count so downstream stages run in parallel, and encrypts them into S3.
  2. Orchestrate. Step Functions chains the Lambdas (TypeScript and Python) under least-privilege IAM, so each stage only touches what it needs.
  3. Track state. DynamoDB job and file tables, provisioned with AWS CDK, let a failed run resume from the step that failed instead of reprocessing the whole file.
  4. Deliver to Connect. I migrated the Customer Profiles ingestion workflow from Python to TypeScript and validated it end to end, from S3 upload to profile creation in Amazon Connect.

Alongside the main flow, I built a PGP encryption proof of concept that confirmed encrypted files decrypt and validate inside the pipeline, and a scheduled EventBridge Lambda that cleans up S3 automatically. Everything shipped through pull-request code review and CI/CD.
